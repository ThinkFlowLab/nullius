**v0.1.0 · First release**

- **Spending caps.** Give a recipe a budget; each unit gets its own cap, and a run stops when it is reached. Costs come from your own price list, with cache writes and one-hour retention priced at their own rates.
- **Rate limits.** A rate-limited run slows down and runs each rate-limited unit once more.
- **Podman and more Docker setups.** The container backend runs on Podman, rootless Docker, rootful Docker with userns-remap, and the Docker that `docker context use` selects.
- **Model providers.** Add several named OpenAI-compatible endpoints, and test a provider's URL and key without spending credits.
- **New benchmark: GAIA** on the Nullius standard. LongMemEval runs on one question type; benchmarks can grant tasks internet access.
- **Safer runs.** Pinned images are checked against registry tags, GPU memory is checked before dense retrievers start, and the relay's container gets its key as a file.
- **More accurate results.** The adjusted rate leaves out stopped trials, merged jobs replace their source shards, and runs that never began count as not run.
- **Benchmark fixes.** SWE-bench grades the actual patch and starts agents in the task environment; each Terminal-Bench task gets tmux; HumanEval Original setup checks run isolated.
- **Interface.** Long names wrap instead of being cut, and a page tells you when it is out of date.

## Install

Install the latest version with [uv](https://docs.astral.sh/uv/) and Python 3.12+:

```bash
uv tool install nullius-eval
nullius serve
```

For an existing unpinned installation, run `uv tool upgrade nullius-eval`.
Open <http://127.0.0.1:5057>.

<summary>Installation options, downloads and validation</summary>

To pin this version, use `uv tool install nullius-eval==0.1.0`.
Alternatively, install the attached wheel with
`uv tool install ./nullius_eval-0.1.0-py3-none-any.whl`.
Add `--force` when replacing an existing tool installation. Settings,
catalogue additions and runs stay outside the installed package;
`nullius paths` shows their locations.

The downloads contain the wheel, source archive and `SHA256SUMS`.
After downloading all three files into one directory, verify them on Linux
with `sha256sum --check SHA256SUMS`.

Release validation targets Linux with Python 3.12: backend and route tests,
installed commands and resources, and user-storage preservation. It does not
establish macOS or Windows support or validate every live benchmark/provider
combination. These are Python packages with a local web UI.
