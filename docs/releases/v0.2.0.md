**v0.2.0 · Desktop benchmarks, Boat VMs and one interface toolkit**

- **Desktop benchmarks.** New: OSWorld2, with OSWorld-V2's own agents and a null control. OSWorld1 defaults to desktop-env v1.0.3. An agent with the computer port runs them through its kit; a benchmark's own agents are chosen like any agent, one job each.
- **New benchmark and agents.** GSMA's Open Telco on the standard. DigitalMate 0.1.13 and 0.1.13-fixes.
- **Boat.** Run each unit's agent, or a VM task, in a Boat VM of its own. The Where step chooses hosts or sandboxes.
- **Model providers.** Define a provider once and pick it by protocol everywhere; choose the serving providers that may answer a model. Old provider settings are still read; `nullius migrate --providers` rewrites them.
- **Run limits and retries.** Each phase's time limit is enforced, an agent's work on a unit is bounded and its model calls capped. `--retries` retries attempts that fail on the infrastructure or the agent.
- **Results.** Repeated attempts read together, with pass@k and pass^k. A Launches page, a reworked trial page, Compare in columns with a Chart view.
- **Interface.** Tables and catalogue cards share one toolkit: search, filters, sort, cards or a table. The builder's Benchmark and Agent steps use the catalogue's cards. Workspaces are managed on one page.
- **Saved recipes** move from the browser to the user data directory on the first visit, with a Recipes page.
- **Judge.** Each job and trial has its own judgement file; overlapping saves and retries no longer lose a judgement.
- **Faster pages.** Pages no longer read every trial of every job, and a workspace's counts are kept on disk.

## Install

Install the latest version with [uv](https://docs.astral.sh/uv/) and Python 3.12+:

```bash
uv tool install nullius-eval
nullius serve
```

For an existing unpinned installation, run `uv tool upgrade nullius-eval`.
Open <http://127.0.0.1:5057>.

<summary>Installation options, downloads and validation</summary>

To pin this version, use `uv tool install nullius-eval==0.2.0`.
Alternatively, install the attached wheel with
`uv tool install ./nullius_eval-0.2.0-py3-none-any.whl`.
Add `--force` when replacing an existing tool installation. Settings,
catalogue additions and runs stay outside the installed package;
`nullius paths` shows their locations.

The downloads contain the wheel, source archive and `SHA256SUMS`.
After downloading all three files into one directory, verify them on Linux
with `sha256sum --check SHA256SUMS`.

Release validation targets Linux with Python 3.12: backend and route tests,
installed commands and resources, and user-storage preservation. It does not
establish macOS or Windows support or validate every live benchmark/provider
combination. These are Python packages with a local web UI.
