**v0.3.0 · An API for other machines, a Leaderboard and task sets**

- **API.** Read results and start runs from another machine: `/api/v1` with tokens made in Settings → API access or by `nullius access`. A single-file Python client, `nullius remote` and `nullius mcp` for MCP clients.
- **Leaderboard.** Agents ranked on capabilities and domains from the workspace's finished runs; every score opens its evidence. Scoring settings choose the benchmarks and weights. `nullius leaderboard` prints the same numbers.
- **Task sets.** List a dataset's tasks, keep named sets and run one, in the builder or with `--set`.
- **Flagging tasks.** A User judge labels failed attempts and flags flawed or ambiguous tasks; the score can leave flagged tasks out. `/flag-tasks` proposes flags from finished runs.
- **Trials.** Each model call kept whole, and the conversation shown call by call. A benchmark's own detail and records on the trial page. A running task shows its steps against its limit.
- **Runs.** Each job keeps an identity across copies and moves; a run says what identifies it and its mean over every planned task. Imported sources each get their own folder.
- **Builder.** Simpler procedures and version choices; each version marked Official or Experiment. A model's reasoning is chosen on the Model step, `--reasoning` on the command line.
- **Catalogue.** LoCoMo's full version with its 446 adversarial questions, and a judge beside its F1 as an experiment. WorkSwarm v0.2.9.
- **Interface.** IBM Plex Sans bundled; icons drawn for their size; errors shown inside the app.
- **Settings.** Your own prices kept in a file of their own; a key file per port when two hosts share an address.

## Install

Install the latest version with [uv](https://docs.astral.sh/uv/) and Python 3.12+:

```bash
uv tool install nullius-eval
nullius serve
```

For an existing unpinned installation, run `uv tool upgrade nullius-eval`.
Open <http://127.0.0.1:5057>.

<summary>Installation options, downloads and validation</summary>

To pin this version, use `uv tool install nullius-eval==0.3.0`.
Alternatively, install the attached wheel with
`uv tool install ./nullius_eval-0.3.0-py3-none-any.whl`.
Add `--force` when replacing an existing tool installation. Settings,
catalogue additions and runs stay outside the installed package;
`nullius paths` shows their locations.

The downloads contain the wheel, source archive and `SHA256SUMS`.
After downloading all three files into one directory, verify them on Linux
with `sha256sum --check SHA256SUMS`.

Release validation targets Linux with Python 3.12: backend and route tests,
installed commands and resources, and user-storage preservation. It does not
establish macOS or Windows support or validate every live benchmark/provider
combination. These are Python packages with a local web UI.
