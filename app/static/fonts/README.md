# Nullius fonts

DM Sans, IBM Plex Mono and Instrument Serif, distributed under the SIL Open Font License 1.1. The unmodified license for each family is included beside the files.

Font assets were obtained from the Google Fonts CSS service; all font requests in Nullius use local static files. Characters outside the font coverage use the system fallback.

Source: https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500&family=IBM+Plex+Mono:wght@400;500&family=Instrument+Serif:ital@0;1&display=swap

The three identity families also have locally served WOFF2 conversions. Production styles use only regular and medium UI/code weights, and regular/italic Instrument Serif. Outlined identity asset provenance is in `../brand/README.md`; source licensing is in the repository’s root `LICENSE`.

The application interface uses the platform system font through CSS; no system font files are bundled. DM Sans remains available for documentation and brand assets. Instrument Serif retains its brand role, and IBM Plex Mono is used for technical text.
