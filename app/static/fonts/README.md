# Nullius fonts

DM Sans, IBM Plex Mono, IBM Plex Sans and Instrument Serif, distributed under the SIL Open Font License 1.1. The unmodified license for each family is included beside the files.

Font assets were obtained from the Google Fonts CSS service; all font requests in Nullius use local static files.

Source: https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500&family=IBM+Plex+Mono:wght@400;500&family=Instrument+Serif:ital@0;1&display=swap
