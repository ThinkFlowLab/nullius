# Production identity

The outlined circle-and-slash mark and Instrument Serif wordmark are supplied production assets. Theme names describe the background. Keep their proportions and internal clear space; horizontal lockups need at least 120px width, marks 16px. CSS masks use the supplied outlines in the current text colour.

`tokens.json` records surface, text and action roles. The application and documentation expose these under their existing CSS names. Outcome, tool and trace palettes remain separately tested. DM Sans regular/medium carries interface and documentation text; IBM Plex Mono regular/medium carries code and identifiers. Instrument Serif regular/italic is reserved for major brand headings. Local WOFF2 files are in `../fonts/`.

The mark follows the existing Nullius circle-and-slash geometry; wordmark lettering is outlined from Instrument Serif. WOFF2 files are conversions of the bundled fonts. Source licensing is in the repository’s root `LICENSE`; the three font OFLs remain beside the fonts in `../fonts/`. These assets do not include a personal identity guide or proposed banners. README media is owned by its separate animation change.
