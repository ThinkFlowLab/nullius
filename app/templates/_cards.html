Slots, in order: `icon`, `title` (exactly one), `check` (the title row, the check at its right); `text`; `badge`*, `note`*; `stat` (up to 3, below a line); `alert`; `action`*; `status`, `tag`*, `meta` (the last row, the meta at its right) (* any number, the others at most one). Plus `href` (its title's link), `id`, `search` (what the search reads) and `keys`. A field's `class` goes on each of its values; `card_label` names a stat when its column header does not, and a value's `label` names it for that item; `style` 'code' sets the text as code; `icon` puts #i- before a note. `icon` values are image URLs: when one item has one, the others show initials; when none has, no icon. -#} {% from '_tables.html' import controls, empty_note %} {#- Each value of `fields` in `item`, as a dict, to the call block with its field. #} {% macro each(item, fields) %}{% for f in fields %}{% set v = item.get(f.key) %} {%- for x in ([v] if v is string or v is mapping or v is number else v or []) if x is not none and x != '' %}{{ caller(f, x if x is mapping else {'text': x}) }}{% endfor %}{% endfor %}{% endmacro %} {#- A value as a pill: its field's class and its own, its tooltip. #} {% macro pill(f, v) %}{% set cls = [f.class, v.class]|select|join(' ') %}{{ v.text }}{% endmacro %} {# A collection of cards (NulliusTable.cards): its controls row, its cards, the note when none passes. `id` names it; `search`, `choices`, `only`, `layout` and each field's `filter` as the table's controls; `sort` the Sort by menu, over the fields that are not blank; `noun` what the live region counts.
