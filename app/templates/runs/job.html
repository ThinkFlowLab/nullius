    Adjusted rate
    Solves divided by the trials that actually ran: it drops the outcomes marked infra, which failed before the agent could be judged. The raw rate is Harbor's mean over every trial, shown beside it only when the two differ. A run in which no trial carries a verdict shows —, never 0%.
    {% if not control %}
    Solved meter
    One unit per trial that ran, solves filled; an infra trial is a hollow unit after a gap. Past 12 trials the units become one bar. A hovered trial row lights its unit.
    {% endif %}
    Tokens · Total
    Under each trial's value a thin bar from zero, on one scale for the column: the largest trial fills its track. Total is the trial start to finish and includes overhead that Env, Agent and Verify do not.
    {% if show_judge %}
    Marks
    solid = recorded hollow ring = judge reading dotted = below the confidence gate
    experimental
    A judge model's reading of each transcript (cause, flags) or of each task's instruction text (Instruction). Shown beside the recorded outcomes, never replacing them; the rates count only the record.
    Lanes
    Each outcome row starts its own readings. A line runs straight into agrees when the recorded outcome allows the judge's cause, and jogs into disagrees when it does not. What is not a finding about the claim stays in the gutter: not asked (a resolved trial is never asked its cause), not judged, below gate (under {{ lanes.threshold if lanes else '0.5' }} confidence), and an Unknown outcome's reading. A cause filters to exactly its trials.
    Tally
    Under the lanes: the Classifier vs judge page's own counts and words. Disagree and Agree always show, over the comparable judged trials; the others only when non-zero. Each opens that page at its status.
    Flags
    One judgment per behaviour, asked of every judged trial. Each flag keeps a fixed number, its place in the question vocabulary. The board lists the flags raised, most raised first; each trial row keeps one slot per flag in number order, filled where the flag was raised.
    {% endif %} {% if show_ins %}
    Instruction
    A judge model's score of each task's instruction text alone, once per dataset and task. An unclear instruction caps every agent on that task. Experimental.
